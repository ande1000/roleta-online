# 🎰 Roleta com Painel de Controle

Sistema de roleta online com painel administrativo que adiciona saldo em **tempo real**.

## 📁 Arquivos

| Arquivo | Função |
|---------|--------|
| `server.js` | Servidor Node.js (WebSocket + Express) |
| `package.json` | Dependências do Node |
| `roleta.html` | Site do jogo (jogador) |
| `painel.html` | Painel de controle (admin) |
